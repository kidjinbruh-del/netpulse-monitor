# Запуск NetPulse с рабочего стола

На Windows установите Python 3.12+ и запустите из каталога проекта:

```powershell
& .\tools\install_shortcut.ps1
```

Скрипт создаст `NetPulse` на рабочем столе для выбранного Python.
При необходимости укажите `-PythonPath C:\Python312\python.exe`.
Альтернатива без установки ярлыка — `open_netpulse.cmd` в каталоге проекта.

Ярлык проверяет зависимости, устанавливает недостающие через pip из requirements.txt,
запускает сервер в фоне, ожидает ответа и открывает операционный центр в браузере.
Повторный клик открывает работающий экземпляр. Занятый чужой порт не освобождается
принудительно. Права администратора и изменение firewall не требуются для локальной
панели; отдельные административные операции внутри приложения требуют своих прав.

Конфигурация и база остаются в каталоге проекта. Ярлык сам не меняет настройки
доступа, поиска устройств, подключений к роутерам и автоматизации.
При первой настройке задайте `web_host: 127.0.0.1` и нужный `web_port` в config.json.
Для отключения автоматического сканирования задайте `lan.auto_scan_min: 0`.
Ненастроенный пример меша можно отключить через `p2p.enabled: false`.

Логи: `logs/launcher.log`, `logs/setup.log`, `logs/server.err.log`,
`logs/server.out.log`, `logs/netpulse.log`. Неудачный запуск показывает сообщение
с путём к логам. `python tools/launch_netpulse.py --no-browser` запускает сервер
без открытия браузера. Launcher рассчитан на локальный HTTP; для HTTPS используйте
настроенное доверенное имя сертификата, проверка сертификатов не отключается.

После перемещения каталога проекта создайте ярлык заново. Docker-стек мониторинга
и удалённые узлы запускаются отдельно согласно инструкции observability;
этот ярлык запускает сам NetPulse с его настроенными фоновыми модулями.
