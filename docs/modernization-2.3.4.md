# NetPulse 2.3.4 — модернизация

## Подтверждённые исправления
- Контекст запроса (body, actor, role) теперь thread-local. Конкурентные HTTP-запросы не подменяют команды и пользователя друг друга.
- Каждый экземпляр HTTP-сервера использует свой handler/API вместо глобального Handler.api.
- JSON должен быть объектом; лимит тела — 1 MiB; некорректная длина, дубли Content-Length и Transfer-Encoding отклоняются. Чтение ограничено 10 секундами, POST закрывает соединение после ответа.
- Вход поддерживает web_users/viewer. Неверные явные GET-токены учитываются в brute-force, запросы без токена до входа не блокируют собственный SPA.
- HTTPS учитывается при проверке Origin и выставлении Secure cookie. Прокси-заголовкам автоматически не доверяем.
- IPv4/IPv6 allowlist использует ipaddress с проверкой корректности адресов/префиксов.
- Рекурсивное маскирование вложенных секретов до усечения записи аудита.
- Из URL убраны токены; API-запросы имеют 15-секундный таймаут; неуспешный вход не сохраняет неверный токен.
- Очередь фоновых заданий ограничена 64 активными/ожидающими; устаревшие результаты очищаются, архив ограничен. Переполнение сообщает 503.
- SQLite закрывает заимствованные соединения после остановки и не возвращает их в закрытый пул.
- SW кэширует только фиксированный список статики того же origin, никогда API/экспорты/query URL; не удаляет чужие кэши и не подменяет отсутствующий JS HTML-страницей.
- Исправлены привязка теста к чужому абсолютному пути и устаревшее ожидание query-token auth.

## Интерфейс и эксплуатация
- Индикатор связи/устаревших данных, отсутствие дублирующего polling при активном SSE.
- Сетка KPI 4/2/1, мобильные формы и уведомления, клавиатурный фокус переключателей, Escape закрывает меню, reduced-motion.
- Убрано автоматическое приглашение к уведомлениям.
- `python -m netpulse --check`: JSON-диагностика зависимостей, конфига, порта, доступа и TLS без запуска мониторинга и без вывода секретов.
- requirements.txt больше не пытается установить Python через pip.
- CI запускает весь pytest на Windows/Linux, проверяет JS и SW. Версия выровнена с README.

## Проверка и ограничения
Локально Windows/Python 3.12: 107 тестов прошли (до правок 86/89). JS синтаксически проверен Node. Веб-интерфейс проверен с MiniService на loopback без реального мониторинга/сканирования сети. Это не end-to-end проверка всех интеграций: WinRM, SNMP, firewall, mesh, CVE и удалённые агенты требуют отдельного стенда. Обновление не развёртывалось на рабочих узлах.

Новые тесты: malformed JSON, лимиты тела, viewer login/RBAC, изоляция серверов и параллельных пользователей, закрытие SQLite, IPv6, маскирование аудита, перегрузка очереди, read-only doctor.

## Обновление
Сделать резервную копию конфигурации и БД обычными средствами, остановить NetPulse, обновить код и зависимости, выполнить `python -m netpulse --check`, запустить и проверить вход/поток/отчёты. Схема данных не менялась. Для отката вернуть предыдущий commit. Долгоживущие cookie и токены остаются существующей моделью проекта; полноценные короткие серверные сессии — отдельная миграция.
