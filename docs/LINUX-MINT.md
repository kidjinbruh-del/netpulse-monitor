# NetPulse для Linux Mint 22.x

Подготовлено для Linux Mint 22.x Cinnamon, MATE и Xfce. Ветка 22 использует
[пакетную базу Ubuntu 24.04](https://linuxmint.com/rel_wilma_whatsnew.php).
Установщик и сервер проверяются в Ubuntu 24.04 VM с настоящей виртуальной сетью.
Полный сеанс Cinnamon/Nemo на Mint отдельно не испытывался.

## Установка

Из домашнего каталога обычного пользователя:

```bash
sudo apt-get update
sudo apt-get install git
git clone https://github.com/kidjinbruh-del/netpulse-monitor.git
cd netpulse-monitor
bash install_mint.sh
```

Не запускайте весь установщик через sudo: пароль администратора запрашивает
только apt. Он установит Python venv, ping, iproute2, инструменты ярлыков и zenity.
Python-пакеты устанавливаются в `.venv`, системный Python не заменяется.
Существующие config.json и база не удаляются.

После установки откройте **NetPulse** в меню Mint → Интернет. Если включён рабочий
стол, туда также копируется `NetPulse.desktop`. Cinnamon/Nemo может запросить
разрешение запуска при первом открытии. Ярлык запускает сервер в фоне и открывает
браузер; повторное открытие использует работающий процесс. Ошибка запуска в
графическом сеансе показывается через zenity, подробности — в `logs/`.

Запуск из терминала: `bash open_netpulse.sh`.
Без браузера: `bash open_netpulse.sh --no-browser`.
Проверка системных предпосылок без изменений: `bash install_mint.sh --check`.

В чистой установке сайт доступен только этому ПК на http://127.0.0.1:8770.
Автоматическое сканирование и пример меша отключены. Для ручного поиска откройте
«Локальная сеть», выберите Ethernet/Wi-Fi и нажмите «Сканировать подсеть».
VPN можно выбрать отдельно. Порты firewall и удалённый доступ установщик не открывает.

## Необязательный автозапуск

User unit подготовлен в `~/.config/systemd/user/netpulse.service`.
Сначала остановите вручную запущенный сервер, затем:

```bash
systemctl --user daemon-reload
systemctl --user enable --now netpulse
```

Теперь ярлык будет открывать панель службы. Остановка службы:
`systemctl --user stop netpulse`. Это пользовательская служба в рамках сеанса;
запуск до входа пользователя требует отдельной настройки администратора.

## Обновление

Сделайте резервную копию через настройки NetPulse, остановите свой экземпляр
(или `systemctl --user stop netpulse` для службы), затем:

```bash
git pull --ff-only
bash install_mint.sh
```

После обновления запустите NetPulse ярлыком либо своей user-службой. Не запускайте
службу и отдельный ручной экземпляр одновременно на одном порту.

## Другие выпуски и ограничения

Mint 21.x использует старую базу; NetPulse требует Python 3.12+. Установщик не
подключает PPA и не заменяет Python ОС. Для Mint 21.x или LMDE с уже настроенным
Python 3.12+ используйте [общую инструкцию Linux](LINUX.md), без обещания полной
проверки этих выпусков. Windows Firewall, Windows-события и DPAPI остаются
Windows-функциями. Основной веб-сервер, LAN-сканер, SQLite и резервные копии
проверены в Linux-стенде; физический MikroTik требует отдельного испытания.
