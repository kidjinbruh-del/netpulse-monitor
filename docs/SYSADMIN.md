# Сисадмин, топология и сценарии обслуживания (2.8.1)

## Доступность и ресурсы

Доступность считается по длительности состояний между ONLINE/OFFLINE. Последний
переход до начала периода задаёт начальное состояние; до первого известного
состояния время неизвестно. Без 95% покрытия процент периода не показывается.
Это оценка по событиям, не договорный SLA: пропущенные события, остановленный
коллектор, изменение часов и редкие опросы ограничивают точность. Отдельно видны
покрытие, время offline и количество переходов. Отсутствие событий не даёт 100%.

Тренд ОЗУ использует реальные монотонные секунды и линейную регрессию. Нужны
3+ точки за 30+ секунд. Горизонт ограничен пятью окнами наблюдения и сутками,
поэтому короткий всплеск не превращается в прогноз на недели. Значения в п.п./мин.

## Остальные источники

- MTR показывает отдельные хопы: `hop`, `ip`, `loss_pct`, `avg_ms`. Потери ответа
  промежуточного роутера не доказывают потери прикладного трафика. Период выбирается явно.
- География — сводка **упоминаний** IPv4 в событиях, не доказательство источника
  атаки. Офлайн-префиксы неполны и могут устаревать. `?` означает неизвестную страну.
- Аудит использует поля `timestamp/user/ip/action/status/details`, а не индексы массива.
- L2 показывает сохранённые `if_name/if_index/switch_ip`, без нового опроса при открытии.

## Proxmox VE

GET `/api/proxmox` читает снимок. Явная кнопка «Опросить PVE» запускает POST
`/api/proxmoxpoll`, возвращающий `job`. Узлы и VM/LXC разделены; CPU — проценты,
RAM — GB / общий GB. Неудачный опрос сохраняет последний удачный снимок со `stale`.

Новые конфигурации проверяют TLS. Для частного CA задайте `proxmox.ca_file`.
Старое явное `verify_tls:false` сохраняется, но интерфейс предупреждает об этом.
Принимается HTTPS origin, включая порт, без логина/пароля в URL. Токен читается
из `NP_PROXMOX_TOKEN` или переменной `proxmox.token_env`; прежний `token_secret`
поддерживается для совместимости. Используйте отдельный токен с правами чтения.

## CVE

POST `/api/cvescan` выполняется только при `cve.enabled:true`, возвращает `job`
и не удерживает HTTP-запрос на время NVD. Проверяется до 100 уникальных продуктов
с непустой версией. Это keyword-кандидаты, а не доказанные уязвимости; выдача NVD
ограничена первыми 20 совпадениями на запрос. Неполная проверка помечается явно.
Сетевой сбой не считается отсутствием CVE. Названия и версии ПО отправляются NVD
только при запуске проверки; `NP_NVD_API_KEY` необязателен и не отдаётся в браузер.

## Топология

Схема показывает логический инвентарь, поскольку API не подтверждает физические
соединения. Пустые слои и произвольные линии убраны; шлюз не объявляется online
лишь из-за наличия маршрута. Отображаются все узлы, с поиском, фильтром состояния,
масштабом и подробностями по клику/Enter. На узком экране карточки перестраиваются.
SVG/PNG используют фактический размер схемы; PNG ограничен 8192 px по большой стороне.

## Runbooks

Сценарии лежат в доверенном `netpulse/runbooks/*.json` и выполняются с правами
процесса NetPulse. Изменять этот каталог должны только администраторы программы.
Открытие парка и подготовка формы ничего не запускают.

Локальная проверка дисков использует Python, возвращает структурированные данные
и работает в Windows/Linux. Остальные текущие PowerShell-сценарии требуют Windows.
Удалённая операция требует hostname/IPv4 и явного подтверждения. Для Spooler нужны
настроенный WinRM и соответствующие права; ошибки PowerShell прерывают команду.
Произвольный текст/кавычки/разделители команд в параметрах не принимаются.

POST `/api/runbookexec` теперь возвращает `job`; результат читается через
`/api/securityresult?job=...`. Это изменение прежнего синхронного контракта.
История содержит исполнителя, цель и код. Не повторяйте изменяющий сценарий,
если предыдущий запуск ещё не завершён.

## Windows: повышенный автозапуск

```powershell
.\tools\install_autostart.ps1 -StartNow
```

Windows запросит UAC. Задача `NetPulse` запускается при входе текущего пользователя,
с Interactive logon и Highest, без сохранения пароля и без аккаунта SYSTEM.
Сначала проверяется существующий слушатель: перезапускать разрешено только
`python -m netpulse` из этого checkout. Чужой владелец порта не завершается.
`start_netpulse.ps1` больше не убивает произвольный процесс на 8770.

Удаление: `tools/install_autostart.ps1 -Remove`. Ярлык обычного открытия панели
сохранён. Установка задачи сама по себе не включает захват и не выполняет runbooks.

## Проверка

Алгоритмы и команды проверяются unit-тестами. Браузерные проверки используют
изолированный сервер и синтетические ответы, включая неполный CVE, ошибку PVE,
27 узлов топологии, PNG и подтверждение runbook. Удалённый Spooler в тестах не
перезапускается. Реальные NVD/PVE/WinRM этой проверкой не сертифицируются.
