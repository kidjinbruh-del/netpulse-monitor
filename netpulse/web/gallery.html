Галерея дашборда

Развитие интерфейса решётки и дашборда. Скриншоты — в хронологическом порядке.
Было: топология (v2.3.1)
SVG force-рендер: узлы, рёбра, панель деталей по клику. Полоски расталкивают узлы.
Нагрузка на шкалу (до правок)
Индексная ось X + max-of-window = цикл «в пик уходит вверх, в тишине плющится». Источник бага.
Нагрузка на шкалу (p95 + floor 100)
95-й перцентиль вместо max: выбросы обрезаны у потолка, фон виден, циклов масштаба нет.
Скролл по времени (5 мин)
Ось X — время, правый край = «сейчас», старые точки уходят за левый край. TwitchTracker‑стиль.
Финал: TwitchTracker‑график
Линии + пунктирное AVG + столбцы алертов снизу + подписи MAX/AVG слева + минутная ось времени.
Дашборд: полоски + сессия 2×2 + таблица парка
Полоски скорости с цветом (🟢 норма, 🟡 близко к пику, 🔴 пик), сетка сессии 2×2 с крупными цифрами, таблица парка с иконками статуса.
