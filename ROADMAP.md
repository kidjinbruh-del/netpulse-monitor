# Roadmap — статус предложений

Все 25 предложений из списка улучшений получили вердикт.
Реализовано — см. [CHANGELOG](CHANGELOG.md). Ниже — судьба остальных.

## ✅ Реализовано (8)

Kick-подобное управление сессиями (ротация токена), аудит действий,
бэкап конфига, logging, webhook-алерты, email-алерты, OpenAPI `/api/swagger.json`,
валидация конфига, Self-Healing (правила → runbook с предохранителями),
SNMP-снэпшоты + diff, SMART-мониторинг, PWA (manifest + SW), топология сети (SVG).

## 🔒 Закрыто окончательно (противоречит архитектуре)

| Идея | Причина закрытия |
|---|---|
| PostgreSQL вместо SQLite | Масштаб проекта — десятки устройств; SQLite WAL покрывает с запасом. Вернуться при 500+ узлах |
| Асинхронный сервер (aiohttp) | Ломает stdlib-философию; клиентов — единицы |
| High Availability (Active-Passive) | Для 2 админов избыточно; ответ — бэкапы + автозапуск |
| Docker-образ | Ядро завязано на Windows (WinRM, netsh, raw sockets) |
| Kick Session | Модель доступа «только админы» без ролей утверждена владельцем |
| Jira/Redmine интеграция | Внешние тикет-системы не используются; журнал — свой service desk |
| Кэш кармы / очередь потоков сторожа | Основано на неверных предпосылках о коде (карма по расписанию, опрос последовательный) |
| i18n (EN) | Интерфейс для внутреннего отдела; RU-язык — требование |
| Разделение server.py на api/-модули | Задокументировано в AGENTS.md; вернуться при 3000+ строк |

## ⏳ Отложено до внешних условий

| Идея | Условие возврата |
|---|---|
| SNMP v3 | Требование министерства; нужен pysnmp или большая доработка BER (auth/priv) |
| Карта сети на CDP/LLDP | Текущая SVG-топология покрывает базу; LLDP требует доступа к коммутаторам |
| Push-уведомления браузера | Нужен VAPID-сервер; webhook/TG закрывают потребность |
| Интеграция Jira | См. выше |
| ES6-модули фронтенда | При конфликтах слияния |
