# Roadmap — отложенные предложения

Идеи оценены, но сознательно отложены. Критерии возврата указаны для каждой.

## При росте масштаба

| Идея | Когда возвращаться | Почему отложена |
|---|---|---|
| PostgreSQL вместо SQLite | 500+ устройств, несколько админов | SQLite WAL достаточен для текущей нагрузки; абстракция БД — большой рефакторинг |
| Асинхронный сервер (aiohttp) | Десятки одновременных SSE-клиентов | Текущих клиентов — единицы; stdlib-философия |
| High Availability (Active-Passive) | Мониторинг стал критичным для производства | Ответ сейчас: автобэкап + автозапуск задачей |
| Разделение server.py на api/-модули | При следующем большом блоке фич | Работает, задокументировано в AGENTS.md |
| Разбор app.js на ES6-модули | При конфликтах слияния между разработчиками | Рефакторинг-риск без функциональной выгоды сейчас |

## Требуют внешних условий

| Идея | Условие возврата | Почему отложена |
|---|---|---|
| SNMP v3 | Требование министерства (152-ФЗ, ISO 27001) | pysnmp — тяжёлая зависимость против ноль-депс; оборудование v3 не поддерживает |
| Интеграция Jira/Redmine | Если отдел переедет во внешнюю систему тикетов | Журнал NetPulse — собственный service desk |
| Docker-образ | Портирование на Linux-сервер | Ядро завязано на Windows: WinRM, netsh, route print, raw-sockets |

## Запланировано (следующие волны)

| Идея | Заметки |
|---|---|
| SMART-мониторинг через WMI + прогноз отказа диска | Продолжение прогноза заполнения |
| Self-Healing (условие → runbook) | Только whitelist-действия, без «перезагрузить роутер»; обязательная запись в аудит |
| Карта сети (топология) | vis.js = зависимость; сначала собрать LLDP/CDP-данные |
| PWA + push | Дешевле — Telegram/Webhook-каналы (webhook уже есть) |
| Email-алерты (SMTP) | После обкатки webhook |
| OpenAPI-схема `/api/swagger.json` | Генерация из ROUTES-словарей |
| i18n (EN) | При публикации для сообщества |
| Валидация config.json при загрузке | Упрощённо, без jsonschema: критичные поля + понятные ошибки |
| История SNMP-конфигурации (снэпшоты + diff) | Продолжение infra-модуля |

## Отвергнуто (противоречит архитектуре)

| Идея | Причина |
|---|---|
| Kick Session (выгонять помощников) | Модель «только админы» без ролей принята владельцем |
| Принудительный переход на async | См. «Асинхронный сервер» |
| Кэш кармы / очередь потоков сторожа | Основано на неверных предпосылках: карма считается по расписанию, сторож опрашивает последовательно |
